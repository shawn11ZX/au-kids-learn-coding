# Week 10, Session A: Mood indicator

**Route:** Pico  
**Time:** About 45 minutes. You may split it across days.  
**Lesson:** Open [Mood indicator](https://projects.raspberrypi.org/en/projects/mood-indicator) (part of Introduction to Raspberry Pi Pico). Use its circuit diagram for every connection.

## Before starting

- [ ] Complete the [previous session](../pico/week-09-session-b.md), or repeat it if the checkpoint was difficult.
- [ ] Have ready: Pico setup, RGB LED of the project type, required resistors, breadboard and wires.
- [ ] Parent preparation: Open “Mood indicator”. Check the RGB LED pin order against the project diagram.

## During the session

1. **Warm up (5 min):** Ask what your child remembers from the last session.
2. **Work together (30 min):** Wire the RGB LED while unplugged, then run the starter program and connect colours to states.
3. **Check understanding (10 min):** Ask: “Which condition selects each colour?” Let him point to the code, drawing or hardware when answering.

## Finished when

He answers the check question in his own words, and the RGB LED shows different colours for different states. If this takes longer, stop at a working point and continue next time.

If stuck: Unplug before changing wires. Compare every connection with the project diagram, then run the last working code.
