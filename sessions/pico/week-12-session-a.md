# Week 12, Session A: Sensory gadget

**Route:** Pico  
**Time:** About 45 minutes. You may split it across days.  
**Lesson:** Open [Sensory gadget](https://projects.raspberrypi.org/en/projects/sensory-gadget) (part of Introduction to Raspberry Pi Pico). Use its circuit diagram for every connection.

## Before starting

- [ ] Complete the [previous session](../pico/week-11-session-b.md), or repeat it if the checkpoint was difficult.
- [ ] Have ready: Pico setup and the input/output parts selected from earlier projects, paper and pencil.
- [ ] Parent preparation: Open “Sensory gadget”. Lay out the reusable parts and ask him to sketch a simple gadget.

## During the session

1. **Warm up (5 min):** Ask what your child remembers from the last session.
2. **Work together (30 min):** Follow the guide to combine an input and output. Keep the first version small enough to finish today.
3. **Check understanding (10 min):** Ask: “What should happen when the input changes?” Let him point to the code, drawing or hardware when answering.

## Finished when

He answers the check question in his own words, and the gadget reads an input and changes an output. If this takes longer, stop at a working point and continue next time.

If stuck: Unplug before changing wires. Compare every connection with the project diagram, then run the last working code.
