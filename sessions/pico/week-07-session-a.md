# Week 7, Session A: LED firefly

**Route:** Pico  
**Time:** About 45 minutes. You may split it across days.  
**Lesson:** Open [LED firefly](https://projects.raspberrypi.org/en/projects/led-firefly) (part of Introduction to Raspberry Pi Pico). Use its circuit diagram for every connection.

## Before starting

- [ ] Complete the [previous session](../python/week-06-session-b.md), or repeat it if the checkpoint was difficult.
- [ ] Have ready: Pico 2 with soldered headers, micro-B USB data cable, breadboard, LED, project resistor, jumper wires, computer with Thonny.
- [ ] Parent preparation: Install Thonny, check the cable carries data, and select Pico 2 MicroPython firmware. Open “LED firefly”.

## During the session

1. **Warm up (5 min):** Ask what your child remembers from the last session.
2. **Work together (30 min):** With the Pico unplugged, copy the circuit from the project diagram. Plug it in, run the starter code, and make the LED blink.
3. **Check understanding (10 min):** Ask: “Which instruction turns the light on, and which controls the delay?” Let him point to the code, drawing or hardware when answering.

## Finished when

He answers the check question in his own words, and the LED blinks under Pico 2 control. If this takes longer, stop at a working point and continue next time.

If stuck: Unplug before changing wires. Compare every connection with the project diagram, then run the last working code.
