# Week 8, Session A: Party popper

**Route:** Pico  
**Time:** About 45 minutes. You may split it across days.  
**Lesson:** Open [Introduction to Raspberry Pi Pico](https://projects.raspberrypi.org/en/collections/physical_computing) and choose “Party popper”. Use its circuit diagram for every connection.

## Before starting

- [ ] Complete the [previous session](../pico/week-07-session-b.md), or repeat it if the checkpoint was difficult.
- [ ] Have ready: Pico setup, breadboard, button or switch, LED, passive piezo if the project calls for it, resistors and wires from the project diagram.
- [ ] Parent preparation: Open “Party popper” and lay out only the parts shown in its circuit diagram.

## During the session

1. **Warm up (5 min):** Ask what your child remembers from the last session.
2. **Work together (30 min):** With power disconnected, build the circuit together. Run the project and identify the input and the light or sound output.
3. **Check understanding (10 min):** Ask: “What does the program read before it decides to pop?” Let him point to the code, drawing or hardware when answering.

## Finished when

He answers the check question in his own words, and a button or switch triggers light or sound. If this takes longer, stop at a working point and continue next time.

If stuck: Unplug before changing wires. Compare every connection with the project diagram, then run the last working code.
