# Week 9, Session A: Beating heart

**Route:** Pico  
**Time:** About 45 minutes. You may split it across days.  
**Lesson:** Open [Introduction to Raspberry Pi Pico](https://projects.raspberrypi.org/en/collections/physical_computing) and choose “Beating heart”. Use its circuit diagram for every connection.

## Before starting

- [ ] Complete the [previous session](../pico/week-08-session-b.md), or repeat it if the checkpoint was difficult.
- [ ] Have ready: Pico setup, potentiometer, LED, correct resistors, breadboard and wires.
- [ ] Parent preparation: Open “Beating heart” and match the potentiometer pins to the diagram before connecting power.

## During the session

1. **Warm up (5 min):** Ask what your child remembers from the last session.
2. **Work together (30 min):** Build and run the guided project. Turn the dial slowly and observe the LED effect at several positions.
3. **Check understanding (10 min):** Ask: “Which number changes as the dial turns, and what does the program do with it?” Let him point to the code, drawing or hardware when answering.

## Finished when

He answers the check question in his own words, and turning the dial changes the LED effect. If this takes longer, stop at a working point and continue next time.

If stuck: Unplug before changing wires. Compare every connection with the project diagram, then run the last working code.
