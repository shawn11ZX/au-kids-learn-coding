# Week 9, Session B: Beating heart

**Route:** Pico  
**Time:** About 60 minutes. You may split it across days.  
**Lesson:** Open [Beating heart](https://projects.raspberrypi.org/en/projects/beating-heart) (part of Introduction to Raspberry Pi Pico). Use its circuit diagram for every connection.

## Before starting

- [ ] Complete the [previous session](../pico/week-09-session-a.md), or repeat it if the checkpoint was difficult.
- [ ] Have ready: Pico setup, potentiometer, LED, correct resistors, breadboard and wires.
- [ ] Parent preparation: Leave the last working wiring in place if possible.

## During the session

1. **Recall (5 min):** Look at what you made in Session A and ask what should happen next.
2. **Build or change (40 min):** Try three marked dial positions: low, middle and high. Print the dial value at each one and write it down. Change one timing or brightness rule, then compare what the LED does at the same positions.
3. **Check (10 min):** Run, demonstrate or inspect the result. Ask what changed and what stayed the same.
4. **Record (5 min):** Write a small table: position, dial value, what the LED did. Add one idea for next time.

## Finished when

The notebook has three dial settings and observations; he can explain the input and output. If this takes longer, stop at a working point and continue next time.

If stuck: Unplug before changing wires. Compare every connection with the project diagram, then run the last working code.
