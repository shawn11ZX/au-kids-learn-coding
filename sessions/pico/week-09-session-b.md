# Week 9 Homework: Beating heart upgrade

**Route:** Pico  
**Type:** Homework. He works on his own. A parent checks the result at the end (5–10 minutes).  
**Time:** About 15–30 minutes, on any day before the next session.  
**Lesson:** Open the [Beating heart “Upgrade your project” step](https://projects.raspberrypi.org/en/projects/beating-heart/7). It is the last step of the project from Session A.

## Before starting

- [ ] Finish [Session A](../pico/week-09-session-a.md) first.
- [ ] Open the saved project from Session A.
- [ ] Ask a parent before changing any wires. Unplug the Pico first.

## Homework

- [ ] Turn the dial to low, middle and high. Write the dial value and what the LED does at each one in a small table.
- [ ] Pick one upgrade from the page: a better paper heart, a blue LED, or a heartbeat sound with the passive buzzer.

If stuck: unplug the Pico, compare every wire with the project diagram, and run the last working code. Then ask a parent.

## Parent check

Ask him to read his table and explain which part is the input and which is the output.
