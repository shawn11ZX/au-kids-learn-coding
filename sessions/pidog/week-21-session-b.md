# Week 21, Session B: Design his own behaviour

**Route:** PiDog  
**Time:** About 60 minutes. You may split it across days.  
**Guide:** Open [SunFounder — Python examples](https://docs.sunfounder.com/projects/pidog/en/latest/python/play_with_python.html) and the printed PiDog V2 guide. Follow the printed V2 guide for assembly and power.

## Before starting

- [ ] Complete the [previous session](../pidog/week-21-session-a.md), or repeat it if the checkpoint was difficult.
- [ ] Have ready: Working PiDog V2, Pi 5, saved action and sensor examples, paper and pencil.
- [ ] Parent preparation: Save a copy of the last working code.

## During the session

1. **Recall (5 min):** Look at what you made in Session A and ask what should happen next.
2. **Build or change (40 min):** Write a short program combining existing actions and one sensor decision. Run each part separately before the full routine.
3. **Check (10 min):** Run, demonstrate or inspect the result. Ask what changed and what stayed the same.
4. **Record (5 min):** Write or draw the result and one idea for next time.

## Finished when

He has a working draft and can explain the drawn states. If this takes longer, stop at a working point and continue next time.

If stuck: Pause at the last successful step in the V2 guide. For moving parts, stop and power off before inspecting them.
