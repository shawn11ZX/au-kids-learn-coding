# Week 1, Session A: Hello world emoji

**Route:** Python  
**Time:** About 45 minutes. You may split it across days.  
**Lesson:** Open [Introduction to Python](https://projects.raspberrypi.org/en/collections/python) and choose “Hello world emoji”.

## Before starting

- [ ] A computer and a little curiosity are enough to begin.
- [ ] Have ready: Computer, browser, internet, notebook.
- [ ] Parent preparation: Open the Introduction to Python collection and find “Hello world emoji”. Check that the coding editor opens.

## During the session

1. **Warm up (5 min):** Ask what he thinks a robot program tells the robot to do.
2. **Work together (30 min):** Follow the project with your child. Have him type the print message, set a variable, and run the program after each change.
3. **Check understanding (10 min):** Ask: “Which line stores the emoji choice, and what changes if you edit it?” Let him point to the code, drawing or hardware when answering.

## Finished when

He answers the check question in his own words, and the first Python project prints a chosen message and emoji. If this takes longer, stop at a working point and continue next time.

If stuck: Read the first error line together, undo the last change, and rerun the last working version.
