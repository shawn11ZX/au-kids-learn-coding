# Week 1 Homework: Hello world challenge

**Route:** Python  
**Type:** Homework. He works on his own. A parent checks the result at the end (5–10 minutes).  
**Time:** About 15–30 minutes, on any day before the next session.  
**Lesson:** Open the [Hello world “Challenge” step](https://projects.raspberrypi.org/en/projects/hello-world/6). It is the last step of the project from Session A.

## Before starting

- [ ] Finish [Session A](../python/week-01-session-a.md) first.
- [ ] Open the saved project from Session A.

## Homework

- [ ] Add three more `print()` lines about things he likes, with emoji.
- [ ] Use one of the sentence starters on the Challenge page, such as `print(f'I ❤️ ...')`.
- [ ] Run it and check every line prints what he expected.

If stuck: read the first error line, undo the last change, and run the last working version. Then ask a parent.

## Parent check

Ask him to point to one variable and show what changes when he edits it.
