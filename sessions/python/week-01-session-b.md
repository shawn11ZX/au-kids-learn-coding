# Week 1, Session B: Hello world emoji

**Route:** Python  
**Time:** About 60 minutes. You may split it across days.  
**Lesson:** Open [Hello world emoji](https://projects.raspberrypi.org/en/projects/hello-world) (part of Introduction to Python).

## Before starting

- [ ] Complete the [previous session](../python/week-01-session-a.md), or repeat it if the checkpoint was difficult.
- [ ] Have ready: Computer, browser, internet, notebook.
- [ ] Parent preparation: Open the saved project or starter project.

## During the session

1. **Recall (5 min):** Look at what you made in Session A and ask what should happen next.
2. **Build or change (40 min):** Make a two-message “robot mood” program. Let him choose the messages and emoji. Ask him to predict the output before each run.
3. **Check (10 min):** Run, demonstrate or inspect the result. Ask what changed and what stayed the same.
4. **Record (5 min):** Write or draw the result and one idea for next time.

## Finished when

He points to the variable and shows how changing it changes the output. If this takes longer, stop at a working point and continue next time.

If stuck: Read the first error line together, undo the last change, and rerun the last working version.
