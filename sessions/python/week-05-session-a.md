# Week 5, Session A: Don’t collide!

**Route:** Python  
**Time:** About 45 minutes. You may split it across days.  
**Lesson:** Open [Don’t collide!](https://projects.raspberrypi.org/en/projects/dont-collide) (part of Introduction to Python).

## Before starting

- [ ] Complete the [previous session](../python/week-04-session-b.md), or repeat it if the checkpoint was difficult.
- [ ] Have ready: Computer, browser, notebook.
- [ ] Parent preparation: Open “Don’t collide!”. Place the Pico parts order using the shopping list so it can arrive before Week 7.

## Order now for Pico Week 7

- [ ] [Pico 2H with pre-soldered headers](https://core-electronics.com.au/raspberry-pi-pico-2-h-with-headers.html), a [micro-B USB **data** cable](https://core-electronics.com.au/usb-a-to-micro-b-cable.html) that fits your computer, and a small breadboard.
- [ ] LEDs, resistors, buttons, a passive piezo, potentiometers and jumper wires from the [Australian shopping checklist](../../11_year_old_robotics_python_curriculum.md#shopping-list). The linked Australian electronics kit covers most parts but needs a white LED and one more RGB LED.

## During the session

1. **Warm up (5 min):** Ask what your child remembers from the last session.
2. **Work together (30 min):** Follow the game project. Change one obstacle or movement rule only after the starter version runs.
3. **Check understanding (10 min):** Ask: “Which rule decides that the player collided?” Let him point to the code, drawing or hardware when answering.

## Finished when

He answers the check question in his own words, and the game runs and has a visible collision rule. If this takes longer, stop at a working point and continue next time.

If stuck: Read the first error line together, undo the last change, and rerun the last working version.
