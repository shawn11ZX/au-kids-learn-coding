# Week 2, Session A: Target practice

**Route:** Python  
**Time:** About 45 minutes. You may split it across days.  
**Lesson:** Open [Introduction to Python](https://projects.raspberrypi.org/en/collections/python) and choose “Target practice”.

## Before starting

- [ ] Complete the [previous session](../python/week-01-session-b.md), or repeat it if the checkpoint was difficult.
- [ ] Have ready: Computer, browser, saved Week 1 work, notebook.
- [ ] Parent preparation: Open “Target practice” and locate the scoring rules in the starter code.

## During the session

1. **Warm up (5 min):** Ask what your child remembers from the last session.
2. **Work together (30 min):** Work through the project. Discuss one branch at a time: first the `if` alone, then the `else`, then the `elif`. For each one, ask which input makes it run.
3. **Check understanding (10 min):** Ask: “What score should this input receive, and why?” Let him point to the code, drawing or hardware when answering.

## Finished when

He answers the check question in his own words, and the game awards points using an `if` decision. If this takes longer, stop at a working point and continue next time.

If stuck: Read the first error line together, undo the last change, and rerun the last working version.
