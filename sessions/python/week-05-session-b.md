# Week 5 Homework: Don’t collide! challenge

**Route:** Python  
**Type:** Homework. He works on his own. A parent checks the result at the end (5–10 minutes).  
**Time:** About 15–30 minutes, on any day before the next session.  
**Lesson:** Open the [Don’t collide! “Challenge” step](https://projects.raspberrypi.org/en/projects/dont-collide/7). It is the last step of the project from Session A.

## Before starting

- [ ] Finish [Session A](../python/week-05-session-a.md) first.
- [ ] Open the saved project from Session A.

## Homework

- [ ] Use different emoji for the player and the obstacles.
- [ ] Change one line of code to make the obstacles move faster.
- [ ] Play three times before and three times after the change. Write down if it became easier or harder.

If stuck: read the first error line, undo the last change, and run the last working version. Then ask a parent.

## Parent check

Ask him to explain the rule he changed and what it did to the game.
