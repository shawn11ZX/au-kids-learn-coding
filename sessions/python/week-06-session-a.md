# Week 6, Session A: Powerful patterns

**Route:** Python  
**Time:** About 45 minutes. You may split it across days.  
**Lesson:** Open [Powerful patterns](https://projects.raspberrypi.org/en/projects/powerful-patterns) (part of Introduction to Python).

## Before starting

- [ ] Complete the [previous session](../python/week-05-session-b.md), or repeat it if the checkpoint was difficult.
- [ ] Have ready: Computer, browser, paper and pencil.
- [ ] Parent preparation: Open “Powerful patterns” and let him choose a simple pattern to draw.

## During the session

1. **Warm up (5 min):** Ask what your child remembers from the last session.
2. **Work together (30 min):** Work through the planning prompts. Let him decide which parts should repeat. Then add one `if` choice, such as picking one of two colours. Help only when an error blocks progress.
3. **Check understanding (10 min):** Ask: “Which part of this pattern could a loop draw for you?” Let him point to the code, drawing or hardware when answering.

## Finished when

He answers the check question in his own words, and the planned pattern runs, uses repetition and makes one `if` choice. If this takes longer, stop at a working point and continue next time.

If stuck: Read the first error line together, undo the last change, and rerun the last working version.
