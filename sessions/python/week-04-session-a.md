# Week 4, Session A: Make a face

**Route:** Python  
**Time:** About 45 minutes. You may split it across days.  
**Lesson:** Open [Make a face](https://projects.raspberrypi.org/en/projects/make-a-face) (part of Introduction to Python).

## Before starting

- [ ] Complete the [previous session](../python/week-03-session-b.md), or repeat it if the checkpoint was difficult.
- [ ] Have ready: Computer, browser, paper and pencil.
- [ ] Parent preparation: Open “Make a face”; have paper ready for a one-minute sketch.

## During the session

1. **Warm up (5 min):** Ask what your child remembers from the last session.
2. **Work together (30 min):** Follow the drawing project. Ask him to sketch the face on squared paper first and mark one feature as an (x, y) point. Then connect a variable or choice to an expression.
3. **Check understanding (10 min):** Ask: “What would the face look like for a different choice?” Let him point to the code, drawing or hardware when answering.

## Finished when

He answers the check question in his own words, and the program shows a face that changes with a choice. If this takes longer, stop at a working point and continue next time.

If stuck: Read the first error line together, undo the last change, and rerun the last working version.
