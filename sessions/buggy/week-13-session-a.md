# Week 13, Session A: Inputs and outputs

**Route:** Buggy  
**Time:** About 45 minutes. You may split it across days.  
**Guides:** Use [Teach Computing’s robot buggy unit](https://teachcomputing.org/curriculum/key-stage-4/physical-computing-project) for the lesson goal and [Kitronik’s buggy tutorials](https://kitronik.co.uk/blogs/resources/online-tutorial-autonomous-robotics-platform-for-pico-motors) if using that kit. Follow your kit maker’s wiring and power directions.

## Before starting

- [ ] Complete the [previous session](../pico/week-12-session-b.md), or repeat it if the checkpoint was difficult.
- [ ] Have ready: Pico, buggy kit, its instructions, USB cable, button/LED test parts if needed, notebook.
- [ ] Parent preparation: Check the buggy kit contents and read its actual connection guide. Follow the kit maker’s electrical and wiring instructions.
- [ ] Kitronik’s published examples target the original Pico. Before relying on the Pico 2 from earlier sessions, confirm support with the seller or have an original Pico H available.

## During the session

1. **Warm up (5 min):** Ask what your child remembers from the last session.
2. **Work together (30 min):** Use Teach Computing Lesson 1 to review input and output. Run an LED/button check before using motors.
3. **Check understanding (10 min):** Ask: “What should the robot read before it starts moving?” Let him point to the code, drawing or hardware when answering.

## Finished when

He answers the check question in his own words, and a button/LED check works before motors are connected. If this takes longer, stop at a working point and continue next time.

If stuck: Stop and disconnect power. Test one motor or sensor at a time using the kit maker’s instructions.
