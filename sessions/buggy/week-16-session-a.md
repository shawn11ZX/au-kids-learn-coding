# Week 16, Session A: Stop before an obstacle

**Route:** Buggy  
**Time:** About 45 minutes. You may split it across days.  
**Guides:** Use [Teach Computing’s robot buggy unit](https://teachcomputing.org/curriculum/key-stage-4/physical-computing-project) for the lesson goal and [Kitronik: ultrasonic sensor](https://kitronik.co.uk/blogs/resources/online-tutorial-autonomous-robotics-platform-pico-ultrasonic-sensor) if using that kit. Follow your kit maker’s wiring and power directions.

## Before starting

- [ ] Complete the [previous session](../buggy/week-15-session-b.md), or repeat it if the checkpoint was difficult.
- [ ] Have ready: Buggy, its distance sensor, cardboard obstacle, ruler, batteries.
- [ ] Parent preparation: Read the kit maker’s sensor connection guide and confirm the signal voltage is safe for Pico GPIO.

## During the session

1. **Warm up (5 min):** Ask what your child remembers from the last session.
2. **Work together (30 min):** Use Teach Computing Lesson 4 for the idea. Read one distance value and print it. Move the cardboard nearer and farther, and check that the number changes in the expected direction.
3. **Check understanding (10 min):** Ask: “What number do you see when the cardboard is close?” Let him point to the code, drawing or hardware when answering.

## Finished when

He answers the check question in his own words, and the buggy prints a distance that changes when the cardboard moves. If this takes longer, stop at a working point and continue next time.

If stuck: Stop and disconnect power. Test one motor or sensor at a time using the kit maker’s instructions.
