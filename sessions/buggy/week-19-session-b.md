# Week 19, Session B: Plan his buggy challenge

**Route:** Buggy  
**Time:** About 60 minutes. You may split it across days.  
**Guides:** Use [Teach Computing’s robot buggy unit](https://teachcomputing.org/curriculum/key-stage-4/physical-computing-project) for the lesson goal and [Kitronik’s buggy tutorials](https://kitronik.co.uk/blogs/resources/online-tutorial-autonomous-robotics-platform-for-pico-motors) if using that kit. Follow your kit maker’s wiring and power directions.

## Before starting

- [ ] Complete the [previous session](../buggy/week-19-session-a.md), or repeat it if the checkpoint was difficult.
- [ ] Have ready: Working buggy, masking tape, cardboard, ruler, notebook.
- [ ] Parent preparation: Set up the course exactly as drawn.

## During the session

1. **Recall (5 min):** Look at what you made in Session A and ask what should happen next.
2. **Build or change (40 min):** Build the first version. Test it three times and record where it succeeds or fails.
3. **Check (10 min):** Run, demonstrate or inspect the result. Ask what changed and what stayed the same.
4. **Record (5 min):** Write or draw the result and one idea for next time.

## Finished when

There is a written goal, drawing, and three trial results. If this takes longer, stop at a working point and continue next time.

If stuck: Stop and disconnect power. Test one motor or sensor at a time using the kit maker’s instructions.
